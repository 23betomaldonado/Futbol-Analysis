# Fútbol Analysis

# Data Dictionary

## Overview

This document defines the data requirements for Fútbol Analysis and describes the variables that will be used for statistical analysis and machine learning models.

The objective of the dataset is to predict football match outcomes using information that was available before each match occurred.

The dataset will contain historical match information, team performance statistics, player statistics, and contextual information.

Each row in the final dataset will represent one football match.

The model will use historical features from both teams to predict the final match outcome.

# Target Variable

The target variable represents the result that the machine learning model will attempt to predict.

## Match Result

Description:

The final outcome of a football match.

Possible values:

Home Win

Draw

Away Win

Data Type:

Categorical

Example:

Home Win = 1

Draw = 0

Away Win = -1

This variable will be used as the output for classification models such as Logistic Regression, Decision Trees, and Random Forest.

# Match Information

These variables provide basic information about each match.

## Match ID

Description:

Unique identifier for each match.

Data Type:

Integer

Example:

102938

Purpose:

Used to uniquely identify matches within the dataset.

## Date

Description:

Date when the match occurred.

Data Type:

Date

Purpose:

Used for chronological ordering and preventing future information from being used during training.

## Competition

Description:

Tournament or league where the match occurred.

Data Type:

Categorical

Examples:

Premier League

La Liga

Champions League

World Cup

Purpose:

Allows analysis across different competitions.

## Season

Description:

Football season when the match occurred.

Data Type:

Categorical

Example:

2025/2026

Purpose:

Allows historical analysis and model evaluation over different periods.

## Home Team

Description:

Team playing at home.

Data Type:

Categorical

Example:

Real Madrid

## Away Team

Description:

Team playing away.

Data Type:

Categorical

Example:

Barcelona

## Home Advantage

Description:

Indicates whether a team has the advantage of playing at their home stadium.

Data Type:

Binary

Values:

1 = Home match

0 = Away match

Purpose:

Home advantage is a known factor that can influence football results.

# Team Performance Features

These variables describe the historical performance of each team before the match.

## Recent Form

Description:

Team performance during recent matches.

Possible calculation:

Points obtained from previous 5 matches.

Data Type:

Numeric

Example:

13 points out of previous 15

Purpose:

Measures current team momentum.

## Average Goals Scored

Description:

Average goals scored by a team before the match.

Data Type:

Numeric

Example:

2.1 goals per match

Purpose:

Measures attacking performance.

## Average Goals Conceded

Description:

Average goals allowed by a team before the match.

Data Type:

Numeric

Example:

0.8 goals conceded per match

Purpose:

Measures defensive performance.

## Expected Goals (xG)

Description:

Expected goals generated by a team based on shot quality.

Data Type:

Numeric

Purpose:

Measures attacking quality beyond actual goals.

## Expected Goals Against (xGA)

Description:

Expected goals a team allows opponents to create.

Data Type:

Numeric

Purpose:

Measures defensive quality.

These variables measure attacking performance.

## Shots Per Match

Description:

Average number of shots taken.

Data Type:

Numeric

Purpose:

Measures attacking activity.

## Shots On Target

Description:

Average shots that require goalkeeper intervention.

Data Type:

Numeric

Purpose:

Measures quality opportunities created.

Percentage of shots converted into goals.

Data Type:

Numeric

Purpose:

Measures attacking efficiency.

## Big Chances Created

Description:

Average number of high-quality scoring opportunities created.

Data Type:

Numeric

Purpose:

Measures offensive danger.

## Possession Percentage

Average percentage of ball possession.

Numeric

58%

Purpose:

Data Type:

Numeric

Numeric

Purpose:

Measures attacking progression.

## Key Passes

Description:

Passes that directly create scoring opportunities.

Data Type:

Numeric

Purpose:

Measures chance creation.

Whether important players are available for the match.

Data Type:

Example:

0 = Injured/Suspended

Purpose:

## Player Performance Metrics

Goals

Assists

Minutes Played

Player Rating

Purpose:

# Context Features

These variables provide additional match information.

## Team Ranking

Description:

Current league position before the match.

Data Type:

Numeric

Purpose:

Represents overall team strength.

## Rest Days

Description:

Number of days since the team's previous match.

Data Type:

Numeric

Purpose:

Accounts for fatigue and scheduling effects.

## Injuries and Suspensions

Description:

Important missing players before a match.

Data Type:

Numeric or Binary

Purpose:

Accounts for squad availability.

# Feature Engineering

Raw data will be transformed into additional variables that may improve model performance.

Examples:

## Attack Efficiency

Formula:

Goals / Shots

Purpose:

Measures how efficiently a team converts opportunities.

## Defensive Efficiency

Formula:

Goals Conceded / Expected Goals Against

Purpose:

Measures defensive performance compared to expectations.

## Form Difference

Formula:

Home Team Form - Away Team Form

Purpose:

Measures performance difference between teams.

## Expected Goal Difference

Formula:

Home Team xG - Away Team xG

Purpose:

Measures attacking advantage between teams.

# Data Quality Requirements

The dataset must:

Only include information available before matches.

Contain accurate historical records.

Avoid duplicate matches.

Handle missing values appropriately.

Maintain consistent formatting.

Prevent data leakage during model training.

# Initial Dataset Goal

The first version of the dataset should contain enough information to support:

Exploratory data analysis.

Correlation analysis.

Linear regression.

Multiple linear regression.

Classification models.

Feature importance analysis.

The initial goal is to create a reliable dataset that allows machine learning models to identify patterns related to football match outcomes.
